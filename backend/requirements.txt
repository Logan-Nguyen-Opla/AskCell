# --- Flow / mass cytometry ingest ---
# FlowKit parses the FCS TEXT segment and applies spillover compensation
# correctly (matrix inversion over the right channel subset). flowutils is its
# compiled kernel -- it ships manylinux cp312 and win_amd64 cp313 wheels, so the
# "no C compiler required" property of this file still holds.
# NOTE: the arcsinh transform is applied in app/flow/fcs_ingest.py, NOT via
# FlowKit's AsinhTransform -- that class implements the GatingML
# param_t/param_m/param_a form, not the arcsinh(x/cofactor) convention the
# cytometry literature uses. See the module docstring.
flowio>=1.3                     # minimal FCS reader/writer (mock generation)
flowutils>=1.2                  # compensation / transform kernels
FlowKit>=1.3                    # FCS parsing + spillover handling

# --- AI agent ---
